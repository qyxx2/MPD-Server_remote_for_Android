# MPD-Server Remote 1.0.2

**Release channel:** Internal sideload
**Android package:** io.github.qyxx2.mpdserver.remote
**Version:** 1.0.2 (versionCode 10002)
**Minimum Android:** Android 8.0 / API 26

## Changes

- Center the active lyric cue in the lyrics viewport and keep surrounding lyric rows symmetrically arranged around it.
- Keep a two-line active cue centered as one complete group; its second line expands from the center and clips at the available horizontal bounds rather than using ellipsis or marquee.
- Limit the visible lyric viewport to complete rows, using seven rows for a one-line active cue and up to eight rows for a two-line active cue.
- Add focused Compose UI regression coverage for active-cue centering, short lyric documents, two-line cues, clipping, manual scrolling and follow behavior.

## Compatibility and setup

- Requires an accessible MPD-Server instance and a configured server address in the app's Settings.
- Playback, Queue, history and device output state remain authoritative on MPD-Server; the app is a remote controller and presentation client.
- This release is distributed as a signed APK for internal sideloading. It is not a Google Play release.

## Installation

Download `MPD-Server-Remote-v1.0.2.apk` from the GitHub Release assets and install it over an existing installation. The APK uses the project's existing unified internal signing identity so upgrades preserve the installed app identity and data.

## Upstream project

This Android client connects to and presents state from the upstream [MPD-Server repository](https://github.com/qyxx2/MPD-Server). The Android client source is maintained separately at [MPD-Server_remote_for_Android](https://github.com/qyxx2/MPD-Server_remote_for_Android).
