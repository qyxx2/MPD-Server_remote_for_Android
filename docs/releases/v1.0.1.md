# MPD-Server Remote 1.0.1

**Release channel:** Internal sideload
**Android package:** io.github.qyxx2.mpdserver.remote
**Version:** 1.0.1 (versionCode 10001)
**Minimum Android:** Android 8.0 / API 26

## Changes

- Replace the launcher icon with the light, minimal orange record-and-waveform identity using the project's `#DE7622` accent color.
- Keep the same branded artwork as the media-notification fallback icon.

## Compatibility and setup

- Requires an accessible MPD-Server instance and a configured server address in the app's Settings.
- Playback, Queue, history and device output state remain authoritative on MPD-Server; the app is a remote controller and presentation client.
- This release is distributed as a signed APK for internal sideloading. It is not a Google Play release.

## Installation

Download `MPD-Server-Remote-v1.0.1.apk` from the GitHub Release assets and install it over an existing installation. The APK uses the project's existing unified internal signing identity so upgrades preserve the installed app identity and data.

## Upstream project

This Android client connects to and presents state from the upstream [MPD-Server repository](https://github.com/qyxx2/MPD-Server). The Android client source is maintained separately at [MPD-Server_remote_for_Android](https://github.com/qyxx2/MPD-Server_remote_for_Android).
