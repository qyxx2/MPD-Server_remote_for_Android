# MPD-Server Remote 1.0.0

**Release channel:** Internal sideload
**Android package:** io.github.qyxx2.mpdserver.remote
**Version:** 1.0.0 (versionCode 10000)
**Minimum Android:** Android 8.0 / API 26

## Highlights

- Native Kotlin and Jetpack Compose Android remote client for MPD-Server.
- Playback status, seek, previous/next, pause/resume and synchronized Now Playing presentation.
- Queue management with server-authoritative ordering, manual-priority behavior, reorder, Play Now/Play Next, clear and save as playlist.
- Music library browsing, search, playlists, favorites and Home sections for recent updates, playback history and recommendations.
- Album artwork and lyrics presentation.
- Android system media session and notification playback controls.
- MPD DAC hardware volume observation and control, with hardware key interaction and volume feedback.
- Queue remaining-time display calculated from the current track's remaining duration plus the durations of the currently visible upcoming Queue items.

## Compatibility and setup

- Requires an accessible MPD-Server instance and a configured server address in the app's Settings.
- Playback, Queue, history and device output state remain authoritative on MPD-Server; the app is a remote controller and presentation client.
- This release is distributed as a signed APK for internal sideloading. It is not a Google Play release.

## Installation

Download MPD-Server-Remote-v1.0.0.apk from the GitHub Release assets and install it over an existing installation. The APK uses the project's existing unified internal signing identity so upgrades preserve the installed app identity and data.

## Upstream project

This Android client connects to and presents state from the upstream [MPD-Server repository](https://github.com/qyxx2/MPD-Server). The Android client source is maintained separately at [MPD-Server_remote_for_Android](https://github.com/qyxx2/MPD-Server_remote_for_Android).
